# 故障排查

本篇按症状给出投屏问题的排查顺序。日志字段与逐层定位方法见 [配置与日志](configuration.md)，机制背景见 [技术架构](architecture.md)。

---

## 症状与排查

| 症状 | 优先排查 |
| --- | --- |
| 手机搜不到设备 | 同一局域网？UDP 1900 是否被防火墙/公用网络配置拦截？托盘「启用投屏」是否勾选？日志有无 `响应 M-SEARCH` |
| 搜得到但点不动 | 手机缓存了旧端口 → 强制重启 App；核对日志 `port_mode` 与 `设备描述被访问` 的 `url_base` 是否带实际端口 |
| 拉完 SCPD 就放弃 | 看日志 `transfer:"identity"` 与 `bytes`；检查 SCPD 响应是否 `Content-Length` 正常、有无 `收到协商请求` 记录私有探测头 |
| 一条 SOAP 都没有 | 控制点把请求发往了错误地址（URLBase / 80 端口）或在能力协商阶段放弃；按 `M-SEARCH → 描述 → SCPD → SOAP` 逐层看日志 |
| 能连上但画面不播 | 日志有 `已拉起播放器` 却无 SOAP fault → 播放器侧问题；先看 `backend=` 是否为 `builtin`，Windows 旧版 exe 会落到 `wmplayer`，请换用内置播放器的新包；macOS / Linux 则装 mpv/VLC 后在设置页「重新探测」 |
| 直播只播十几秒 | 多为 WMP 把 HLS 当静态列表读，播完分片即 EOS；确认日志 `backend=builtin`（内置 mpv 原生支持 HLS），或换其他 `CapFull` 后端 |
| 托盘图标一直是琥珀色 | 这是「未在播放」的正常状态（内置 mpv 待机也如此）；投屏中变绿色，关闭投屏变灰阶。状态文案见托盘菜单首项 |
| 全屏马上缩回 | 控制点起播后发送 `Seek`；程序已对不支持命令行跳转的后端改为「只同步进度、不重启播放器」 |
| 清晰度低 | 片源由手机端选流决定；Sink 不声明标清档，请在视频 App 投屏设置里选 1080P/4K |
| 右键退出关不掉 | 查看日志是否有 `收到退出请求 → 资源清理完成 → PC-Cast 已退出`；`make smoke` 可回归退出链路 |
